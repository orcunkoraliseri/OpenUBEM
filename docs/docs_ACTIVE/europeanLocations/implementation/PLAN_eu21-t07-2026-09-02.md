## 4. Code facts, with line citations — `scripts/eu21/05_group_cutters.py`

- `_split_wings()` `:887` — recursive `_split_once()` loop. **`:894`: `if len(finished) + len(pieces) > 8: raise Refusal("WING_TREE_FAILED")`** — the 8-piece cap. `:903` raises the same token when a piece cannot be split.
- `cut_wings()` `:1093` — `:1097` refuses when `len(wings) < 2`; `:1249` refuses when the assembled circulation is not a single hole-free Polygon.
- Circulation assembly `:1216`: `combined = _polygons_only(set_precision(unary_union([core_world] + band_geoms)...))`. Each band in `band_geoms` is an axis-aligned `box` built in **its own wing's frame** (`:1173-1181`) and only then rotated to world — so at an angled junction two bands cross at that angle and their union outline steps. This is `T07` (a).
- `:1163` `band_lo, u_far = minx - 0.5, minx + LANDING` (one-flat leaf arm, `DD-8` stub).
- `:1168` `band_lo = (min(reach) - LANDING) if reach else (minx - 0.5)` (root wing).
- **`:1170-1174`**: `if odd_through and xs and reach and xs[-1] >= max(reach) - 1e-9: u_far = xs[-1]` **else** `u_far = (max(reach) + LANDING) if reach else maxx`. The `else` branch pushes the band `LANDING` (1.50 m) **past the last cut, into the last cell**, so that flat is cut around the band's end and comes back as two lobes joined by a neck → `C4`. This is `T07` (c). The same overshoot exists at the low end via `:1168`.
- `_junction(w, parent_w)` `:979` — returns the junction point of a wing and its parent. `_connector()` `:626`, `_bridge()` `:645` — the fallbacks; `_bridge` is what draws the stepped joins that survive to the sheet.
- `exterior_group(poly)` `:1264` and `_dispatch_group(poly, k, grp2)` `:1293` — how a light-well plate (`DD-7`) is re-routed to its exterior's group. `cut()` `:1301` is the entry point.
- `cut_convex()` `:296`; the same `LANDING` overshoot pattern at `:364-365` — **out of scope here**, T03 does not touch `cut_convex`.
- Constants `:28-48`: `CORRIDOR_W = 1.80` · `LANDING = 1.50` · `BAND_MIN_W = MIN_FLAT_W = 3.0` · `COURTYARD_MIN_VOID_SIDE = 6.0` · `MIN_WING_W = 3.0` · `CONVEX_GROUPS` · `WING_GROUPS`.

`scripts/eu21/03_build_rules_html.py`: `ABSORB` `:149`, `CLOSE` `:165` (shared, the law — steps 5 and 6), `SPEC` `:174`
(per group `match` / `plate` / `core` / `cut` / `scheme` / `refuse`, each a list of one-line bullets). Sheet numbers are
`SPEC[g]["num"]`. **Step 3 of a sheet is the `core` list; step 4 is the `cut` list.**

### T01 — `T07` (b): stop refusing complex exteriors at eight pieces

**What.** `WING_TREE_FAILED` costs 29 of the 68 refusals, 12 of them `COURTYARD` light-well plates that `DD-7` rerouted
to their exterior's group. Raise the ceiling and give the decomposition a fallback instead of a refusal.

**Why.** Prompt §5 `T07` (b): *"light-well plates whose exterior has > 8 reflex vertices refuse `WING_TREE_FAILED`
(12 of the 26 courtyard refusals) — raise the piece cap or fall back to the convex cutter on the exterior's MRR frame."*

**How.**
1. In `_split_wings()` `:894`, raise the piece cap from `8` to a module constant `MAX_WING_PIECES = 14`. Keep the raise
   as a guard against runaway recursion, not as a target.
2. In `cut_wings()`, wrap the decomposition so that a `Refusal("WING_TREE_FAILED")` raised by `_split_wings()`,
   `_wing_tree()`, `_reduce_to_k_wings()` or `_alloc_k()` — **and only that token** — falls back to
   `cut_convex(poly, k, grp)` on the plate's own MRR frame, tagging the result `out["scheme"] = "wing_fallback_convex"`
   and `out["notes"]["fallback"] = "WING_TREE_FAILED"`. A refusal raised *by the fallback itself* propagates unchanged.
3. Do not touch the `:1249` refusal (circulation not a single hole-free Polygon) — that one is a real geometric failure,
   and a plate that reaches it has already been cut; it must stay a refusal.

**How to test.** A `python -c` harness, no pytest run: load the module with `_load_module`, take the eleven

### T02 — `T07` (a): one junction rectangle, stubs trimmed to it

**What.** At a wing junction the root band and the child bands are boxes in different frames, so their union is a stepped
outline that costs `C5` (point count / simple outline) and `C6` (2.50 m facade) on COMPLEX 11, L 4, U/T 3.

**Why.** Prompt §5 `T07` (a): *"wing junctions — the union of a root core and angled child stubs gives a stepped
circulation outline (`test05_U_OR_T_SHAPE.png` 29235, `test05_COMPLEX…` 31075, `way/432864641`): one junction rectangle
in the root frame, stubs trimmed to it."*

**How.**
1. For each child `j` with `parent[j] = p`, build **one junction rectangle** in the **parent's** frame, centred on
   `junctions[j]`, `CORRIDOR_W` across the parent's band direction and `CORRIDOR_W + LANDING` along it, clipped to `poly`.
2. Trim the child's own band so it starts at the boundary of that rectangle rather than overlapping into the parent —
   subtract the junction rectangle from the child band before the union, then add the rectangle back once.
3. Union order becomes `[core_world] + junction_rects + trimmed_band_geoms`. The existing `_bridge()` /
   band-growing fallback stays as the last resort and must not be removed.
4. After the union, apply the existing clean-up path unchanged. Do not add a new simplification pass.

**How to test.** Same harness. On the three named plates (`29235`, `31075`, `way/432864641`) and on all 21 `COMPLEX`
+ 10 `U/T` + 6 `L` FAIL plates: report per plate the circulation's **point count before and after**, whether `C5` and
`C6` would now pass (reuse `04_group_tests.py`'s own check functions by import — do not re-implement them), coverage, and
overlap. Redraw `EU-21/cutter_demo/demo_{L_SHAPE,U_OR_T_SHAPE,COMPLEX_MULTI_WING}.png` and **look at them** before
reporting. Expect the stepped outline gone; report any plate where it is not.

### T03 — `T07` (c): end the band at the cut when the next cell is a through-flat

**What.** `C4` costs 22 plates (COMPLEX 9, U/T 7, COURTYARD 2, SLAB 2, L 2): a flat cell wraps the end of a corridor and
erodes into two lobes.

**Why.** Prompt §5 `T07` (c): *"`C4` lobes on U/T (7) and COMPLEX (9): a flat cell wraps a corridor end — end the band at
the cut, not `+ LANDING`, when the next cell is a through-flat."*

**How.** In `cut_wings()` `:1170-1174` only:
- `u_far`: when the largest element of `reach` is a **cut** (`xs[-1] >= max(reach) - 1e-9`) **and** the cell beyond it is
  a through-flat (`M_w == 1`, or `odd_through` and it is the last cell), set `u_far = xs[-1]` — the band ends **on** the
  cut. The existing `odd_through` special case at `:1170-1171` becomes one branch of this rule, not a separate one.
  When the largest element of `reach` is a **child junction**, `+ LANDING` stays: the corridor has to reach into the child.
- `band_lo` `:1168`: apply the mirror rule at the low end — when `min(reach)` is a cut and the cell below it is a
  through-flat, `band_lo = xs[0]`.
- Leave `:1163` (the `DD-8` one-flat leaf stub) exactly as it is.
- Do **not** touch `cut_convex()` `:364-365`; the convex groups pass 50/50 and are out of scope.

**How to test.** Same harness, over all 22 `C4` plates plus the seven convex representatives at `k ∈ {2,3,4,5,6,7,8,9,12}`
as a regression. Report: `C4` pass/fail per plate using `04`'s own check, coverage, and any plate that flipped from PASS
to FAIL or from drawn to refused. A convex regression that changes any of the 63 outcomes is a **stop-and-report**.
