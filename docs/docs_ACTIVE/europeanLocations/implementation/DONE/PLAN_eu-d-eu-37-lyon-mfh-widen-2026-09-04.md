Placed immediately after the existing `if 2 <= dwellings <= 12 and storeys <= 4: return "MFH", None` line, so
the full function reads (only the new middle line is added, nothing else in the function changes):

```python
def derive_bdtopo_building_type(
    dwellings: int | None, storeys: int | None, is_attached: bool | None
) -> tuple[str | None, str | None]:
    """Apply the ruled `D-EU-04-G` (Option G1) two-signal derivation, fail-closed."""
    if dwellings is None:
        return None, MISSING_OBSERVED_DWELLING_COUNT
    if storeys is None:
        return None, MISSING_OBSERVED_STOREY_COUNT
    if dwellings in (13, 14):
        return None, TYPOLOGY_DWELLINGS_IN_REGISTRY_GAP_13_14
    if dwellings == 1 and storeys <= 4:
        return ("TH" if is_attached else "SFH"), None
    if 2 <= dwellings <= 12 and storeys <= 4:
        return "MFH", None
    if 2 <= dwellings <= 12 and 5 <= storeys <= 9:
        return "MFH", None
    if dwellings >= 15 and storeys >= 5:
        return "AB", None
    return None, TYPOLOGY_SIGNALS_DISAGREE
```

Do **not** widen the `AB` bucket, the `storeys <= 4` single-dwelling bucket, or add anything for the
8 (`dwellings >= 15 & storeys <= 4`) or 2 (`dwellings == 1 & storeys >= 5`) outlier shapes — those are
explicitly out of scope for this ruling (too few to generalize a rule from; see the decision request §4).
