What this is. A control: scripts/eu21/06_nocore_control.py re-cuts every TEST_01 plate into k equal-area flats using only the plate's own frame and equal_area_x (both read, unmodified, from 05_group_cutters.py) — no corridor, no core. Scores only C1 (coverage) and C4 (no lobed flat), the two checks that still mean something without circulation; C2/C8/C9/C10 are circulation checks and are reported N/A, never PASS.

What this is not. Not an acceptance path (DD-7): it never gates DD-1 and never replaces TEST_01. Not an energy result: no EnergyPlus run stands behind any number here (D-EU-55).
