## Executive Summary

`layoutAssigner` is a new `resolution_mode` that replaces real building footprints with **pre-validated DOE/ASHRAE 90.1 prototype EnergyPlus models**, scaled to match the real building's total floor area. This avoids the fragility of dynamic floor-plan generation (`layoutgenerator`, parked in `docs/docs_TODO/`) while preserving full multi-zone fidelity for complex programs (Outpatient: 119 zones, Hospital: 58, SuperTall: 256).

## 4. Architecture (unchanged from v2, with corrections)

| Step | Standard modes | `layout_assign` |
|---|---|---|
| IDF base | Blank template | Baseline prototype IDF (transitioned to 23.1, T08) |
| Geometry | Footprint + `extrude_geometry()` | Pre-built, X/Y vertices × √S |
| Zones | `build_zones()` | Already in baseline (see §3.1) |
| Loads/Schedules/HVAC | `assign_*()` | Already in baseline; scale absolute levels × S |
| Outputs | `write_outputs()` | **Purge baseline `Output:*`, then** `write_outputs()` |
| Context shading | `discover_context()` | Skipped (`num_context_buildings=0`) |

Scaling math (unchanged): S = A_real / A_baseline; X'=X·√S, Y'=Y·√S, Z unchanged. Density loads (W/m², Flow/Area) scale implicitly; **absolute** quantities scale explicitly by S.
