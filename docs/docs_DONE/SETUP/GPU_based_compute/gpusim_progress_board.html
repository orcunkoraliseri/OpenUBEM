On the Windows RTX A400 (4 GB CUDA), M4 reached 21.66 bldg-yr/s at B = 10,000 (65.2× 1-core E+), M5 delivered the fail-closed pipeline switch, M6 added Perez solar gains (+0.01–0.23 %), M7+ added modal layered walls (0.0009 % float32 on thick walls), 3D ray-traced neighbour shading, and multi-zone dwellings (−0.22 to −0.92 %), and M8 simulated all four European 3D neighbourhoods (3,832 homes, 43,989 thermal zones, 523,530 surfaces) in 48.3 min with R² = 0.9825.

gpusim is our GPU-native re-implementation of EnergyPlus 23.1's heat balance engine, built from one portable C/CUDA/Metal header and flat-CSR zone-parallel solver. M0–M3 ran on Mac (M2 Pro); M4–M8 ran and passed on Windows (NVIDIA RTX A400, 4 GB VRAM, native EnergyPlus 23.1.0, zero Windows TDR resets).
