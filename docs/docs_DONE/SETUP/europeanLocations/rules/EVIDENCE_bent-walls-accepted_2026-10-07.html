What a bent wall between flats looks like

Each floor is cut into flats. The rule book asks that the wall between two flats run in one straight line. A bent wall is a wall between flats that turns a corner inside the building, so one flat hooks around its neighbour.

The flats keep their correct size and every other rule passes. The bend changes the drawing, not the floor area that the energy model uses, which is why the rule book only reports it and never fails a home for it.

Below are 11 real homes from the 499 whose only problem is a bent wall, picked at random in each city and drawn to scale from the adopted models. Red circles mark the corners where a wall between flats bends.
