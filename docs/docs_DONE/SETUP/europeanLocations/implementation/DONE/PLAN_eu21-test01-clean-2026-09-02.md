### `D-EU-77` — the cutter measures corridor contact the way the check measures it

A cutter that chooses a corridor by one metric while the check scores it by another cannot converge. The cutter's
contact metric is therefore **defined to be the check's**: the length of the real shared edge between the flat and

`flat.buffer(0.01, cap_style=3, join_style=2).intersection(circ.exterior).length`. No cutter code may score contact
any other way. Ratified by the director 2026-09-02 on the measurement in `FINDING 235`.
